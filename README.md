
# Mine Personal AI Assistant

A personal AI assistant project with a Streamlit chat interface.

## Features

- Chat-style interface
- Chat history and saved conversations
- Voice input and text-to-speech support

## Requirements

- Python
- Dependencies listed in `installed_versions.txt`

## Run locally

1. Clone or download this repository.
2. Open a terminal in the project folder.
3. Install the required dependencies.
4. Start the Streamlit app using the command configured for this project.

## Project structure

- `app.py` — main application
- `voice.py` — voice-related functionality
- `chat_input_with_voice.py` — chat input and voice support
- `side.py` — sidebar and chat-history functionality
- `Frontent/` — frontend files

## Note

This project is under development. Features and setup instructions may change.
